The Docs Plan — what is kept current, and what makes it happen

Nine docs are the necessary ones. They are the only ones kept current, and keeping them current is no longer something anyone has to remember — it is a gate that fails. Everything else is retired behind a signpost.

The rule, in one line: when work lands, the docs that describe it are updated in the same session, and the message where it lands carries the link. The board is where the state is read — what is next and what is done — so everything that lands touches it, along with the Master Plan it has to agree with and the Shipped log that records what actually went live.

What makes it happen

a mechanism, not a promise — because the promise is what kept failing

1One source. docs/doc-map.json maps each doc to the files it describes. This page is generated from it, so the plan and the gate cannot drift apart.
2CI fails. The Docs gate step runs scripts/doc-check.mjs --ci: if a commit touches mapped code and carries no doc link, the check goes red and names the docs it is missing.
3A hook says it out loud. A Stop hook prints the same list at the end of every turn, so it does not depend on anyone thinking to look.
4And the claim is checked against reality. Publishing a doc also bumps its stamp in docs/doc-versions.json (node scripts/stamp-doc.mjs <id>). The gate compares the two: a doc named in a commit whose stamp did not move fails the build and is named. Pasting a link is no longer enough.
5Bypassing is visible, not blocked. Docs: n/a — <reason> in the commit message passes, and the reason goes into the history. A gate that cannot be bypassed gets switched off; one that records the bypass stays on. Same reasoning as the lint budget.
What this still does not do, said plainly. The stamp proves a doc was republished, not that the republish contained anything useful — and the stamp itself could be bumped by hand without publishing. That moves a false claim from satisfied by copy-paste to a deliberate false entry, which is the difference worth having, not a guarantee. And none of it can block a push while main has no branch protection: the check goes red and visible, and nothing stops. Knowing about both beats discovering them.
